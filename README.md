# ECB Rate Hikes and Eurozone Unemployment — Replication Package

**Paper:** *ECB Rate Hikes and Eurozone Unemployment: A Difference-in-Differences Approach*
**Authors:** Alexandru-Cristian Nicu, Gabriel Mourad, Vlad-Ovidiu Ciurea
**Date:** April 2026

This folder contains everything needed to reproduce every figure and table that appears in the paper.

## Folder layout

```
.
├── 1_clean_data.R              # Downloads + cleans all Eurostat / ECB data
├── 2_descriptive_evidence.R    # Produces Table 1 and Figures 1–4
├── 3_reduced_form.R            # Produces Tables 2–3 and Figures 5–6
├── data/                       # Cached cleaned data (regenerated by script 1)
│   ├── panel_clean.rds
│   ├── panel_clean.csv
│   ├── debt_2021.rds
│   ├── trade_exposure.rds
│   └── ecb_rate_monthly.rds
├── figures/                    # PDF figures used in the paper
└── tables/                     # LaTeX tables used in the paper
```

## Requirements

- **R** ≥ 4.1 (tested on 4.3)
- Internet access (script 1 pulls live data from Eurostat and, as a fallback, Wikipedia)
- R packages are installed automatically by `pacman` on first run:
  `tidyverse`, `eurostat`, `lubridate`, `rvest`, `kableExtra`, `ggrepel`,
  `fixest`, `modelsummary`

No LaTeX distribution is required to run the scripts; LaTeX is only needed if you
want to compile the paper from the generated `.tex` table fragments.

## How to reproduce all outputs

Open R (or RStudio) in this folder so that the working directory is the project root,
then run the three scripts in order:

```r
source("1_clean_data.R")
source("2_descriptive_evidence.R")
source("3_reduced_form.R")
```

Equivalently, from the command line:

```bash
Rscript 1_clean_data.R
Rscript 2_descriptive_evidence.R
Rscript 3_reduced_form.R
```

Script 1 takes a few minutes (it downloads ~6 Eurostat tables). Scripts 2 and 3
each run in under a minute. The `data/` folder is already pre-populated, so if
you only want to regenerate figures and tables you can skip script 1 and run
scripts 2 and 3 directly.

## Data sources

All data are pulled live from the Eurostat API via the `eurostat` R package and
from the ECB Statistical Data Warehouse (hard-coded rate-change dates).

| Variable                  | Eurostat code        |
|---------------------------|----------------------|
| Unemployment rate         | `une_rt_m`           |
| Government debt           | `gov_10dd_edpt1`     |
| GDP per capita            | `nama_10_pc`         |
| Population density        | `demo_r_d3dens`      |
| Sectoral GVA (tourism)    | `nama_10_a64`        |
| Population by age group   | `demo_pjangroup`     |
| Russian gas imports       | `nrg_ti_gas`         |
| Total gas supply          | `nrg_cb_gas`         |
| Bilateral trade (SUTVA)   | `ext_lt_intratrd`    |

If a Eurostat call fails (rare), the script falls back gracefully: the Russian
gas share has a Wikipedia fallback, and the trade-exposure measure has a
gravity-based fallback computed from `nama_10_gdp`.

## Notes

- The 10-country baseline is: **Treated** — IT, EL, ES, PT, FR (debt/GDP > 90% in 2021); **Control** — DE, NL, AT, FI, IE. Belgium and Luxembourg are excluded because of their extreme intra-Eurozone trade openness.
- The treatment date is **1 July 2022** (the month of the ECB's first hike on 27 July 2022).
- Standard errors are clustered at the country level throughout.
